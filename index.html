HTML (Lenguaje de Marcado de Hipertexto, del inglés HyperText Markup Language) es el componente más básico de la Web. Define el significado y la estructura del contenido web. Además de HTML, normalmente se usan otras tecnologías para describir la apariencia o presentación de una página web (CSS) o su funcionalidad o comportamiento (JavaScript).

CSS (por sus siglas en inglés, Cascading Style Sheets u Hojas de Estilo en Cascada) es un lenguaje de diseño gráfico que se utiliza para definir y crear el aspecto visual de un documento escrito en lenguaje de marcado como HTML o XML
